# Spesifikasi Aplikasi Next Starter

## Features Spec
- Sebagai guest saya bisa melihat informasi mengenai aplikasi Teersebut
- Sebagai guest saya bisa login menggunakan username dan password
- Sebagai user admin saya bisa mengelola (CRUD) data semua user
- Sebagai user, saya bisa mengupdate data profil saya sendiri
- sebagai user saya bisa mwengganti password
- sebagai user admin saya bisa mengelola role user


## Frontend
- Landing Page
- Login Page
- Admin Panel


## Backend
- Aunthentication Api
- User Management Api
- Role Management Api
